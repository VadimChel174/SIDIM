# Сайт оценки визита в МИДиС

Готовая статическая версия для GitHub Pages. Для работы не нужны React, Node.js или сборка проекта.

## Где что менять

- `index.html` — весь текст и структура страницы.
- `style.css` — цвета, размеры, расположение и мобильная версия.
- `script.js` — работа звёзд, форма обратной связи и ссылки.
- `assets/` — логотип, маскоты, иконка и изображение ссылки.

## Главные настройки

Откройте начало файла `script.js` и найдите объект `CONFIG`:

```js
const CONFIG = {
  businessName: "МИДиС",
  yandexReviewUrl: "ССЫЛКА_НА_ЯНДЕКС_КАРТЫ",
  webhookUrl: "ССЫЛКА_НА_GOOGLE_APPS_SCRIPT",
  clientId: "midis-visit",
  redirectDelay: 1900,
};
```

- `yandexReviewUrl` — куда переходят посетители после оценки 4 или 5.
- `webhookUrl` — адрес Google Apps Script, который записывает ответы в таблицу.
- `redirectDelay` — задержка перед переходом на Яндекс.Карты в миллисекундах.

В архиве уже стоят ссылки из предыдущей версии сайта.

## Как посмотреть на компьютере

Откройте файл `index.html` двойным кликом. Для проверки отправки оценок лучше опубликовать сайт на GitHub Pages.

## Как заменить сайт на GitHub Pages

1. Распакуйте архив.
2. Откройте репозиторий `MIDIS` на GitHub.
3. Замените старые файлы содержимым папки `MIDIS-GitHub-Pages`.
4. Проверьте, что `index.html` находится в корне репозитория.
5. Сохраните изменения через `Commit changes`.
6. Через несколько минут обновите адрес сайта.

## Как редактировать в VS Code

1. Установите Visual Studio Code.
2. Выберите `Файл → Открыть папку` и откройте папку сайта.
3. Редактируйте `index.html`, `style.css` и `script.js`.
4. Сохраняйте изменения сочетанием `Ctrl + S`.

## Логика формы

- Оценка отправляется анонимно в подключённый Google Apps Script.
- После 1–3 звёзд посетитель может выбрать причины и написать комментарий.
- После 4–5 звёзд открывается карточка МИДиС на Яндекс.Картах.
- Имя, телефон и электронная почта не запрашиваются.
